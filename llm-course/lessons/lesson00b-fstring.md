# 第 0 课补充：f-string 字符串格式化专讲

> 你是 Java 程序员，这节全程用 Java 类比。学完这节，字符串拼接就再也不会用错。

## 1. 它是什么：带 `f` 前缀的字符串，`{}` 里能放任何表达式

```python
name = "jy"
age = 18
print(f"我叫{name}，今年{age}岁")     # 我叫jy，今年18岁
```

**注意那个小写 `f`**：它写在引号前面，表示"这个字符串里允许 `{}` 嵌入变量"。忘了写 f，`{name}` 就原样输出成字面文本——新手第一大坑。

## 2. Java 类比：为什么它比 String.format 好用

```java
// Java：占位符和变量分离，多了少了要对数
String.format("我叫%s，今年%d岁", name, age);
```

```python
# Python f-string：变量直接写在句子里，所见即所得，不会错位
f"我叫{name}，今年{age}岁"
```

本质都是模板，但 f-string 把"模板和变量"合成一体，可读性和维护性碾压式胜出。

## 3. `{}` 里是"表达式"，不是只能放变量

只要是合法 Python 表达式，都能塞进去：

```python
price = 42.5
count = 3

f"总价：{price * count}"          # 表达式计算 → 总价：127.5
f"姓名大写：{name.upper()}"       # 调用方法 → 姓名大写：JY
f"列表长度：{len([1, 2, 3])}"     # 内置函数 → 列表长度：3
f"三目：{'成年' if age >= 18 else '未成年'}"   # 条件表达式 → 成年
```

## 4. 格式说明符：冒号后面跟"格式"（重点！）

语法：`{表达式:格式说明}`。记住这几个就覆盖 95% 场景：

| 写法 | 含义 | 示例 | 输出 |
|---|---|---|---|
| `{x:.2f}` | 保留 2 位小数 | `f"{3.14159:.2f}"` | `3.14` |
| `{x:,}` | 千分位逗号 | `f"{1234567:,}"` | `1,234,567` |
| `{x:>8}` | 右对齐，总宽 8 | `f"{42:>8}"` | `'      42'` |
| `{x:<8}` | 左对齐（默认就是左） | `f"'ab':<8"` | `'ab      '` |
| `{x:^10}` | 居中 | `f"{'hi':^10}"` | `'    hi    '` |
| `{x:05d}` | 补零到 5 位 | `f"{42:05d}"` | `00042` |
| `{x:.1%}` | 百分比 | `f"{0.856:.1%}"` | `85.6%` |
| `{d:%Y-%m-%d}` | 日期格式化 | `f"{today:%Y-%m-%d}"` | `2026-08-29` |

可以**组合**：`{price:,.2f}` = 千分位 + 两位小数 → `f"{1275000.5:,.2f}"` → `1,275,000.50`

对 Java 老手：`{x:.2f}` ≈ `String.format("%.2f", x)`，思想完全一样，只是写进了 `{}` 里。

## 5. 实战最常用的三个场景

```python
# ① 拼接多个值（最常见）
print(f"{key}: {value}")

# ② 对齐输出表格
print(f"{'商品':<10}{'价格':>10}")
print(f"{'苹果':<10}{5.5:>10}")

# ③ 金额/数字规范显示
print(f"合计：{total:,.2f} 元")
```

## 6. 三个小坑

1. **想输出花括号本身**：写两个 `f"{{字面量}}"` → `{字面量}`
2. **引号嵌套**：Python 3.12+（你是 3.13）里外层内层可以用同一种引号了，`f"{"a"}"` 合法；老版本要外双内单
3. **调试神器**：`f"{age=}"` 会输出 `age=18`（变量名和值一起打），排查时特别快

## 过关练习

用一条 f-string 打印：`合计：1,275,000.50 元`（数据源 `total = 1275000.5`）。

```python
total = 1275000.5
print(f"合计：{total:,.2f} 元")   # 这就是标准答案
```
