# RAG 前置专讲：这一课的全部新概念，一次讲清

> RAG 是"把公司文档接进大模型"的主流技术，也是阶段 6 的毕业设计。
> 这篇把四个新概念讲透，全用你会的类比，零算法。

## 1. 为什么需要 RAG？—— 模型的"记忆截止"问题

大模型的知识停在**训练完成那一刻**。你问它"你们公司领料流程怎么走"，
它从没见过你们的文档，只能**一本正经地编**（这叫幻觉 hallucination）。

RAG 的思路朴素得像查资料写论文：**别背了，先查再答。**

```
用户提问
   ↓
① 检索：从你的文档库里，找出和问题最相关的几段
   ↓
② 生成：把"找到的段落 + 问题"一起给模型
   ↓
模型基于你给的资料回答（资料里没有的，它老实说不知道）
```

## 2. 核心概念一：Embedding（向量化）—— 把文字变成一串数字

计算机不懂"意思"，只懂数字。**Embedding 就是把一段文字变成一串数字（向量）**，
且**意思相近的文字，向量也相近**。

```
"轴承"      → [0.12, 0.87, 0.03, ...]   （向量 A）
"深沟球轴承" → [0.13, 0.86, 0.04, ...]   （向量 B）← 和 A 很近
"液压油"    → [0.95, 0.21, 0.67, ...]   （向量 C）← 和 A 很远
```

**关键点**：这种"相近"是**语义**上的——"轴承"和"深沟球轴承"字面不完全一样，
但意思近，向量就近。这就是 RAG 能实现**语义搜索**（而非关键词匹配）的原因。

你们平台的 `BAAI/bge-m3` 就是干这个的模型：**文字进，向量出**。
类比：它不是生成文字的模型，是个"文字→坐标"的转换器，把每段话映射到高维空间的一个点。

## 3. 核心概念二：向量数据库 —— 给向量做"索引 + 近邻搜索"

普通数据库存文字，靠 SQL 的 `LIKE` 匹配关键词。
向量数据库存**向量**，查询方式只有一个核心操作：**找最相似的 N 个**（近邻搜索）。

```
SELECT ... WHERE 语义最接近"轴承库存多少" ORDER BY 相似度 DESC LIMIT 5
```

**类比你熟的**：
- 建库存向量 ≈ 建索引（离线做一次）
- 查询 ≈ 把问题向量化后，在库里跑"最近邻"搜索
- Chroma 就是这个向量数据库（开源、轻量、文件型，适合学习）

## 4. 核心概念三：文档切分（Chunking）—— 大文档切成小块

为什么不整篇文档直接向量化？两个原因：
1. **模型上下文有限**——整篇塞进去太长、太贵
2. **检索要精准**——用户问"退货流程"，你希望检索到的是"退货"那一小段，
   而不是整本手册（整篇向量的"平均值"会让细节丢失）

所以先**按段落/固定长度切成小块**，每块单独向量化、单独存。检索时按"块"返回。

**类比**：整本书没法按"书的平均意思"检索；切成段落、标注页码，才能查哪段答哪段。

## 5. 完整流程（写代码前先背下来）

```
【离线准备：建库】（跑一次就行，像建索引）
  文档 → 切成块（TextSplitter）
      → 每块 embedding 成向量（bge-m3）
      → 存进 Chroma（带原文，检索时能取回）

【在线问答：每次提问】
  问题 → embedding 成向量
      → Chroma 里搜最相似的 top-k 块 → 取回原文片段
      → 拼进 prompt："以下是参考资料：{片段}。请根据资料回答：{问题}"
      → LLM 生成回答
```

## 6. 你会用到的新组件（LangChain 生态）

| 组件 | 干什么 | 对应概念 |
|---|---|---|
| `langchain_text_splitters` 的 `RecursiveCharacterTextSplitter` | 切块 | 概念 3 |
| `OpenAIEmbeddings`（指向 bge-m3） | 文字→向量 | 概念 2 |
| `Chroma`（langchain_chroma） | 存向量 + 近邻搜索 | 概念 3 |
| `Document` | LangChain 里"带元数据的文本块" | 数据结构 |

**感受一下框架的价值**：切分、向量化、存库、检索——四件事，LangChain 各给一个组件，
你只需把它们**串起来**。这正是你学了裸写（练习 01-03）+ 框架（练习 04）后的集大成。

## 7. 一个必须知道的坑：embedding 和对话是"两个不同的模型"

| | 对话模型 | Embedding 模型 |
|---|---|---|
| 例子 | glm-5.3-flash | BAAI/bge-m3 |
| 输入 | 文字 | 文字 |
| 输出 | **文字** | **向量（数字）** |
| 用途 | 回答问题 | 算相似度 |

代码里它是两个独立的客户端/调用，别混。也是不同的计费。
