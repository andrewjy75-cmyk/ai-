# solutions/ —— 参考答案目录

> ## ⚠️ 重要警告：写完跑通（或卡死 30 分钟）才准看！
>
> 看答案的时机决定它的价值：
> - **写完跑通后看** → 对照自己的思路，找差距，收获最大
> - **卡死 30 分钟后看** → 带着问题看，能看懂"自己差在哪一步"
> - **一开始就看** → 只是"读过"，不是"会写"——你练的就是从零写出来的能力

## 使用纪律（自己定的规矩）

1. 先读 `exercises/exXX/README.md` 的题面和验收标准
2. 自己写，跑通为止
3. 跑通了再看答案，对比：**思路差在哪？我的写法有隐患吗？**
4. 卡死超过 30 分钟 → 可以看答案，但看完要**自己重写一遍**（不能粘贴）
